# Ayla Power Monitor v1.1.0 — патч

Один запуск `main.py` для Windows/PyCharm і Raspberry Pi. Патч накладається поверх v1.0.1; **не видаляйте `.env` та `data/`**.

## Оновлення

1. Зупиніть програму або сервіс.
2. Розпакуйте патч у корінь проєкту із заміною файлів.
3. `pip install -r requirements.txt`
4. Додайте до свого `.env` (не копіюйте поверх нього):

```env
WEB_HOST=127.0.0.1
WEB_PORT=8096
# Для захисту веб-API встановіть випадковий довгий токен:
WEB_ACCESS_TOKEN=replace_with_long_random_secret
# Лише після налаштування публічного HTTPS-тунелю/домену:
# PUBLIC_BASE_URL=https://your-domain.example
```

5. Запустіть `main.py` кнопкою Run у PyCharm. Локальна панель: `http://127.0.0.1:8096`.
6. Для браузера введіть `WEB_ACCESS_TOKEN` у форму входу. Токен зберігається тільки у sessionStorage вкладки.

**Telegram Mini App:** відкриття з кнопки в `/start` працює тільки коли задано `PUBLIC_BASE_URL` з реально доступною HTTPS-адресою, яка проксуює до вебсервера. У Telegram авторизація здійснюється перевіркою підписаного `initData`, його строку дії та `TELEGRAM_ADMIN_IDS`. Telegram Web App кнопку видно в приватному чаті бота. Без публічного HTTPS працює лише локальна вебпанель, кнопка Mini App не показується.

**Безпека:** не публікуйте порт 8096 напряму в інтернет; використовуйте HTTPS reverse proxy або тунель з контролем доступу. Не встановлюйте `WEB_HOST=0.0.0.0`, якщо не налаштували захист і мережевий екран. Для локального тестування без токена дозволено доступ лише з localhost; у production задайте токен. Не додавайте токени до Git.

## Інтерфейс

- Темні KPI-картки з фактично спостережуваним і невідомим часом.
- 24-годинна шкала, погодинна теплова карта за 7 днів, історія розривів.
- Автоматичне оновлення кожні 30 секунд, мобільна адаптація.
- Жодних зовнішніх JS/CDN-залежностей.

**Точність:** відсутність heartbeat не доводить відключення мережі. Windows працює у тестовому режимі. Розрив містить і час завантаження Raspberry Pi. Перші години до встановлення монітора позначаються як невідомі.

**Примітка:** `widget-sandbox` не є інтегрованим у Telegram Bot API; v1.1 використовує стандартний Telegram Mini App, а експериментальний renderer з попередньої версії залишається окремим.
